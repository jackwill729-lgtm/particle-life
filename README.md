# Particle Life

Touch-friendly particle life simulator in a single `index.html` (no dependencies), made for Android phones.

- **Tap**: new random rules · **Drag**: stir · **Pinch**: zoom/pan · **Long-press, two-finger tap or ⚙**: settings
- Presets: Cells, Bugs, Critters, Snakes, Flowers, Chains, Eyes
- Rules and settings live in the URL hash, so a link reproduces the setup.
